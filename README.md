# Anime Icon Studio

Anime Icon Studio is an open-source desktop application for downloading anime artwork from booru sites, detecting faces, generating expression icons, and exporting sprite sheets.

## Current Version

0.0.1 (Project Started)

## Planned Features

- Download images from Danbooru
- AI anime face detection
- Character recognition
- Duplicate removal
- Expression sorting
- Sprite sheet generation
- Discord emoji export
- Windows executable (.exe)
